Privacy policy

Last updated: 2026-11-10

ytp-rclone is a personal OAuth client. Its only user is the owner of this GitHub account.

Data accessed

With the owner's authorization, rclone running on the owner's own computer reads, uploads, updates and trashes files in the owner's own Google Drive. It does this only to maintain a private podcast feed.

Storage and sharing

  • The OAuth token is stored only on the owner's computer, in an encrypted rclone configuration.
  • No Google user data is sent to the developer, to any server operated for this app, or to any third party.
  • No data is sold, used for advertising, or used to train models.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
